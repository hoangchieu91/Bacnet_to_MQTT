Standard BACnet File Transfer
Dùng AtomicWriteFile để ghi file lên File Object của thiết bị.


CPO-RL4 / CPO-PC6A:

✅ Application file (.app): upload qua File Object instance 1

✅ Config backup: download từ File Object

⚠️ Firmware core (low-level): cần ECY Configurator / Niagara N4


Địa chỉ:

• BACnet/IP: 192.168.20.50

• MS/TP qua router: 8700:5 (network:node)


CLI:

python3 bacnet_file_transfer.py upload --address 192.168.x.x --file-instance 1 --path app.file

📖 Quick Reference

Baud rate phổ biến:

• CPO-RL4, CPO-PC6A: 38400 (default)

• Thiết bị cũ: 9600 hoặc 19200

• Thiết bị mới cao cấp: 76800


Node address:

• Pi (sniffer): 127 (passive, không cần token)

• Pi (scanner): 127 (master, tham gia token ring)

• Đừng dùng address đã có trên bus!


Kiểm tra kết nối:

• ls /dev/ttyUSB*

• sudo dmesg | grep USB
