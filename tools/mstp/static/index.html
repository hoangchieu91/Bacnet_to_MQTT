📖 Quick Reference

Baud rate phổ biến:

• CPO-RL4, CPO-PC6A: 38400 (default)

• Thiết bị cũ: 9600 hoặc 19200

• Thiết bị mới cao cấp: 76800


Node address:

• Pi (sniffer): 127 (passive, không cần token)

• Pi (scanner): 127 (master, tham gia token ring)

• Đừng dùng address đã có trên bus!


Kiểm tra kết nối:

• ls /dev/ttyUSB*

• sudo dmesg | grep USB

⚡ BACnet MS/TP là gì?

Token Passing Protocol

MS/TP (Master-Slave/Token-Passing) chạy trên RS-485. Các node tham gia vòng token ring: ai giữ token mới được phép gửi frame.

Token Ring: Node 1 ──token──→ Node 5 ──token──→ Node 12 ─→ ... ↑ │ └──────────────── token ←──────────────────────┘ Mỗi node giữ token → gửi 1+ frame → pass token → ...
  • Master nodes (0-127): tham gia vòng token, poll slaves
  • Slave nodes (0-254): chỉ trả lời khi được hỏi
  • Baud rate tiêu chuẩn: 9600, 19200, 38400, 76800

Node Monitor

Quét bus tìm tất cả node (0-127). Hiển thị grid trạng thái: ■ Online, ■ Offline, ■ Unknown.

Click vào node xem chi tiết: Object Name, Vendor, Model, Firmware, Location.

📡

Bus Health Sniffer

Passive sniffer bắt mọi frame trên bus MS/TP. Phân tích:

  • Token rotation time
  • Frame rate per node
  • CRC errors (CRC8 header + CRC16 data)
  • Bus utilization %
  • Pathology detection (silence, collision, junk)
📤

File Transfer

Upload/Download file qua BACnet AtomicWriteFile / AtomicReadFile. Hỗ trợ thiết bị CPO-RL4, CPO-PC6A.

  • Chọn file từ danh sách File Objects trên device
  • Upload firmware, config, schedule
  • Download backup, log
⚙️

Network Config

Cấu hình thông số mạng MS/TP cho Pi:

  • Serial port (/dev/ttyUSB0)
  • Baud rate (9600-76800)
  • Node address (0-127)
  • Max Masters, Max Info Frames
